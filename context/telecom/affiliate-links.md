## Rules for this file

- Add a row only for a programme that is actually signed and active, with the
  network or partner that issued the link.
- Copy the tracking URL exactly as issued. One row per provider and landing page.
- Never record commission amounts, rates, or bonuses here. The coach reads this
  file; keeping the amounts out means they cannot influence a comparison.
- A link must land on the provider's own page for the plan or service named in
  "Applies to", not on a comparison site.
- Remove a row as soon as the programme ends or the link stops working, and
  update "Last checked" whenever this file changes.
