# CLAUDE.md

Richtlijnen voor Claude Code (claude.ai/code) bij het werken in deze repository.

## Project

**Belgian Savings Coach**: een spaarcoach voor de Belgische markt.

De repository staat nog aan het begin: er is nog geen code, geen gekozen stack en
er zijn nog geen build-, test- of lintcommando's. Werk deze CLAUDE.md bij zodra
die er zijn (stack, commando's, mappenstructuur, architectuur).

## Werkafspraken

- Communiceer met de eigenaar in het **Nederlands**.
- Code, identifiers en commitberichten in het Engels, tenzij anders afgesproken.
- Houd rekening met de Belgische context: bedragen in euro, Belgische
  datumnotatie (dd/mm/jjjj) en Belgische fiscale regels rond sparen.
- Voeg bij nieuwe functionaliteit ook tests toe, zodra er een testopstelling is.

## Nog in te vullen

- Gekozen stack en hoe je dependencies installeert
- Commando's voor build, tests (ook een enkele test) en lint
- Overzicht van de architectuur
